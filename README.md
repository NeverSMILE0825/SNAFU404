# FUNDS ARE SNAFU / $SNAFU404

Single-page, dependency-free Ethereum meme-token website. All source and locally optimized artwork are included.

## Run
Open `index.html` in a browser, or serve with `python -m http.server 8080`. Upload the folder contents to GitHub Pages, Netlify, or another static host. No npm install or build command needed.

## Prelaunch checklist
- Replace the contract placeholder in `index.html` once the address is deployed and verified.
- Replace header/social placeholder links with actual verified official X and Telegram addresses.
- Verify any claimed V3 liquidity lock on chain before changing `LOCK PLANNED` to `LOCKED`.
- Update token metrics if launch parameters change.
- Add verified social preview metadata, a favicon, and analytics as desired.

## Images
All website illustrations live in `assets/`. The story is fictional satire and should not be used to assert an actual Binance loss or breach. This website is not affiliated with Binance or Ethereum Foundation.

## Design notes
Fonts use Google Fonts with local fallbacks; everything else can load locally. The site has a mobile menu, gallery modal, CA copy button, progress indicator, reduced-motion accessibility, and section anchor navigation. There is no wallet-connect feature.
